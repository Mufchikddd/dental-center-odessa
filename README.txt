Dental Center Odessa — сайт (адаптований під телефони, планшети, ПК)

ВАЖЛИВО ПРО СТРУКТУРУ
Заливайте ВЕСЬ вміст архіву, зберігаючи папки: index.html, style.css, app.js, папки img/ та api/, файл vercel.json.
Папка api/ потрібна для відправки заявок у Telegram (на Vercel вона працює автоматично).

ЗАЯВКИ З ФОРМИ → TELEGRAM (налаштовується один раз)
1) Створіть бота: у Telegram відкрийте @BotFather → /newbot → вигадайте назву й ім'я (має закінчуватись на bot).
   BotFather надішле ТОКЕН (виглядає як 123456789:AAH...). Нікому його не показуйте.
2) Відкрийте свого бота та натисніть Start (бот не може писати першим).
3) Дізнайтесь свій chat id: напишіть боту @userinfobot — він відповість числом Id.
   (Для групи: додайте бота в групу, напишіть там повідомлення і відкрийте
   https://api.telegram.org/bot<ТОКЕН>/getUpdates — у "chat":{"id":...} буде число зі знаком мінус.)
4) У Vercel: проєкт → Settings → Environment Variables → додайте дві змінні (для Production і Preview):
     TELEGRAM_BOT_TOKEN = токен із кроку 1
     TELEGRAM_CHAT_ID   = число з кроку 3 (кілька отримувачів — через кому)
5) Deployments → останній деплой → ⋯ → Redeploy (змінні діють лише на нові деплої).
6) Перевірка: на сайті заповніть форму — повідомлення прийде в Telegram.
   Якщо не прийшло: Vercel → проєкт → Logs → фільтр /api/lead.

Токен ніколи не вписуйте в index.html/app.js і не заливайте на GitHub. Якщо токен «засвітився» —
у @BotFather виконайте /revoke і оновіть змінну у Vercel.

ВІДЕО В HERO
У index.html у тегу <source data-src="..."> можна вказати власний mp4 (H.264, ~720p, до 3–4 МБ).
Постер: додайте poster="img/poster.jpg" до тегу <video id="heroVideo">.

Мінімальні браузери: iOS 15+, Chrome/Edge 105+, Firefox 110+.
